# Mobile-Only MVP 功能 To-Do（多 AI 共创 App）

> Created: 2026-03-17
> Status: Planning
> Source: 用户产品构思 + Claude 分析

## 核心定位（共识）

> 手机端必须 **独立成立，不依赖 Mac / 后端 / 长期记忆系统**
> 每次使用都能获得可沉淀成果，而不是单次问答

---

## 功能清单

### 1. 个人知识资产沉淀系统

**目标：每次讨论 → 可积累 → 可回顾 → 有长期价值**

- 每次讨论结束自动生成：总结、决策、关键观点、待办（可选）、灵感点
- 保存为「知识卡片」，可按主题分类
- 可长期形成「个人认知书 / 思想库」

> 用户原创理解：每次讨论都是一个兴趣话题，经多 AI 叠加沉淀后形成长期成果，像在写一本属于自己的书

### 2. 成果打卡 / 完成感系统

**目标：让用户感到"事情推进了"**

- 每个话题可标记为：已完成 / 待跟进 / 继续讨论
- 下次打开 App 可快速查看进度
- 无需保留完整上下文，仅使用总结内容

> 用户原创理解：用总结性内容即可，不依赖上下文，判断是否值得继续讨论

### 3. 历史共识回顾系统

**目标：形成成长轨迹**

- 自动记录过去的决策与共识
- 新问题可关联历史结论
- 提供参考而非强绑定

### 4. 多 AI 视角切换（无需预设角色）

**目标：让用户主动控制回答风格**

- 同一问题可切换：严谨分析 / 创意发散 / 综合平衡 / 快速结论
- 本质：不同 Prompt 模板
- 不等待多个 Agent，控制感强，手机操作友好

### 5. 社交共创模式（可选扩展）

**目标：多人参与同一问题**

- 发起人创建话题，多人提交观点
- AI 汇总并分析冲突点，输出群体结论

> 用户理解：类似拼单，多人输入 → AI 汇总 → 得出统一方向

### 6. 灵感触发讨论系统

**目标：让用户"不知道聊什么也能用"**

- 用户点击「来点灵感」→ 随机话题 → 自动分类 → 用户选择方向 → 开始共创讨论
- 数据来源可选：新闻 API / 热点榜单 / 随机问题库 / 公开内容源

> 用户原创理解：AI 像伙伴一起探索，而不是回答问题

### 7. AI 伙伴式讨论模式

**目标：从问答 → 对话陪伴**

- AI 提出问题 → 用户表达观点 → AI 回应并延伸 → 循环讨论
- 减少"工具感"，增加情感粘性，更像协作思考

### 8. 场景预设入口

**目标：降低使用门槛**

- 提供快速入口：做决定 / 头脑风暴 / 分析问题 / 灵感生成

### 9. 多 AI 共识生成（核心能力）

**特点：无角色分工、无预设职责**

- 多模型接收同一 Prompt，各自生成完整观点
- 系统进行：共识提取 / 分歧分析 / 综合结论

> 用户核心理解：同一张白卷 → 不同答案 → 提炼最平衡结果

### 10. 手机端独立价值原则

- 不依赖 Mac
- 不依赖后端复杂部署
- 不依赖长期记忆
- 不要求用户输入复杂 Prompt
- 短时间即可获得成果

5. AI 伙伴模式

6. 历史共识回顾
7. 场景预设入口
8. 视角切换

9. 社交共创模式
