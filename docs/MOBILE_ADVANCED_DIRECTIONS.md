# 5 个进阶产品方向（超越原 MVP 清单）

> Created: 2026-03-17
> Status: Brainstorm
> Context: 基于 SparkRing 已有多模型基础设施，提出比原 Mobile MVP 清单更具差异化的方向

---

## 1. 🧪 思维盲区扫描器 (Blind Spot Scanner)

**一句话**：把你的任何想法/计划/决策丢进来，多 AI 帮你找出你没想到的盲区。

**为什么强**：
- 给了一个极其具体的使用理由："我有个想法，帮我挑毛病"
- 输出天然结构化：逻辑漏洞、信息盲区、情绪偏见、替代方案、风险预警
- 每次扫描结果就是一张可保存/分享的「思维体检报告」

**实现路径**：复用 Discuss 三阶段 + 定制 system prompt（让每个模型从不同认知偏误角度审视），加评分卡 UI。约 2 周。

**爆款因素**：人人都有"我觉得这个想法很好"的时刻。分享"AI 给我的想法打了 72 分"截图，传播力强。

---

## 2. 📓 AI 决策日记 (Decision Journal)

**一句话**：记录每个决策 → 多 AI 分析 → 跟踪结果 → 复盘成长。

**为什么比"知识资产沉淀"强**：
- "知识资产"太抽象，用户不知道往里放什么
- "决策日记"有明确输入触发："我今天做了一个决定"
- 天然有时间线：决策 → 预测 → 回顾 → 复盘
- 多 AI 帮你从不同角度评估决策质量
- 3 个月后回看自己的决策记录 + AI 分析 → 强烈成长感

**实现路径**：
- 决策输入表单（问题 + 选项 + 选择 + 理由）
- 多模型并行评估（风险、机会成本、长期影响）
- IndexedDB 存储 + 日历视图
- 30 天后本地通知推送复盘提醒

**无后端**：✅ 纯 IndexedDB + 本地通知

---

## 3. 🎙️ AI 辩论秀 (AI Debate Show)

**一句话**：给一个话题，两个 AI 正反对辩，你当评委打分。

**为什么强**：
- 共识是理性产物，辩论是娱乐产物。手机端用户在碎片时间要的是趣味
- 已有 Discuss 交叉审查机制，改为正反方辩论只需调 prompt
- 输出格式天然适合消费：开场陈述 → 反驳 → 总结陈词 → 评委点评
- 用户可以选立场、出"追问"牌打断 AI，互动感极强
- 每场辩论自动生成「辩论精华卡」→ 小红书/朋友圈直接发

**实现路径**：在 Discuss Phase 2 交叉审查基础上改造为多轮正反方结构，加辩论 UI（左右对战布局、回合计数、评委评分面板）。约 2-3 周。

**爆款因素**：★★★★★ — 话题本身就是传播素材。

## 4. 🔬 内容消化器 (Content Digester)

**一句话**：粘贴任何文章/内容，多 AI 从不同角度帮你消化——5 分钟读完别人 1 小时的内容。

**为什么比"灵感触发"强**：
- 灵感触发有冷启动问题（题库质量决定体验）
- 内容消化器输入是用户已有的内容（文章、微信文章、读书笔记），没有冷启动
- 多 AI 各司其职：摘要 / 批判 / 实操要点 / 关联推荐
- 输出为结构化「阅读笔记卡」→ 自然汇入知识资产系统
- 手机场景：通勤时看到一篇文章 → 粘贴 → 5 分钟深度理解

**实现路径**：新增"消化模式"入口，接受文本输入，用 4 个不同 prompt 模板并行调用已有多模型 Chat。约 1-2 周。

**无后端**：⚠️ URL 抓取需 CORS 代理，但粘贴文本完全无后端。MVP 先做粘贴版。

## 5. 🎯 每日一辩 / Daily Challenge

**一句话**：每天一个话题，3 分钟参与，AI 帮你形成立场，积累你的观点档案。

**为什么比原 list 所有方向都强**：
- 唯一能形成日活习惯的功能
- 不需要用户想话题、不需要外部 API
- 流程极短：看话题 → 选立场 → 看多 AI 分析 → 修正立场 → 保存
- 每天 3 分钟，30 天后有 30 张「观点卡」→ 个人价值观图谱
- 成就系统：连续 7/30/100 天
- 社交属性：同话题立场对比

**话题来源方案**：
- 方案 A：内置 365+ 话题 JSON（无需任何 API）
- 方案 B：用已配置的 AI 模型按日期种子动态生成（一次小模型调用）
- 方案 C：结合用户历史兴趣 + 日期种子个性化生成

**无后端**：✅ 完全纯前端

**爆款因素**：★★★★★ — Wordle 式"每日打卡" + 多 AI 差异化 + 立场可分享

## 对比总结

| 方向 | 比原 list 强在哪 | 难度 | 爆款 | 无后端 |
|------|-----------------|------|------|--------|
| 思维盲区扫描器 | 具体场景锚点 > 通用共识 | ⭐⭐ | ★★★★ | ✅ |
| AI 决策日记 | 有时间线+复盘 > 静态知识卡 | ⭐⭐ | ★★★★ | ✅ |
| AI 辩论秀 | 娱乐消费 > 严肃分析 | ⭐⭐ | ★★★★★ | ✅ |
| 内容消化器 | 用户已有内容 > 冷启动题库 | ⭐ | ★★★★ | ⚠️ |
| 每日一辩 | 日活习惯 > 随机使用 | ⭐⭐ | ★★★★★ | ✅ |

**如果只做一个：每日一辩** — 同时解决获客（话题分享）、留存（打卡习惯）、沉淀（观点档案）三个核心问题。

## 6. 🧬 认知进化追踪器 (Cognitive Evolution Tracker) — 终极形态

**一句话**：每日一辩的升级版。不只追踪"你的观点"，而是追踪"你的思维方式本身在如何进化"。

**对标**：思维版 Apple Health / Oura Ring — 量化认知赛道目前是空白市场。

### 与每日一辩的区别

| | 每日一辩 | 认知进化追踪器 |
|---|---------|--------------|
| 记录什么 | 你对 X 话题的立场 | 你做决策的**思维模式** |
| 输出 | 观点卡片 | 认知画像 + 进化曲线 |
| 30 天后 | 30 个观点 | "你的思维在这些维度上成长了" |
| 留存动力 | "有趣" | "我在变聪明" |
| 付费点 | 弱 | Pro 版深度报告 + 个性化训练 |

### 认知维度追踪

每次互动后，AI 标注用户的认知特征（6-8 个维度滑动均值）：

- 偏好直觉 vs 数据驱动
- 风险偏好：冒险 vs 保守
- 思考深度：表面 vs 深层
- 视角广度：单一 vs 多元
- 立场弹性：固执 vs 开放
- 决策速度：犹豫 vs 果断

### 月度认知进化报告（自动生成）

> 「你的认知进化报告 — 2026年3月」
> - 决策速度提升 23%（从犹豫型 → 果断型）
> - 多元视角得分从 4.2 → 7.8（你越来越能看到对立面）
> - 你仍然在"风险评估"上偏直觉，建议多练习数据驱动场景

### 为什么是终极形态

1. **Quantified Self 赛道**：认知追踪是空白市场
2. **复购理由更强**：不是"有趣"而是"我在成长"
3. **付费点清晰**：基础版免费打卡，Pro 版深度报告 + 历史趋势 + 个性化训练题
4. **口碑传播**：分享的不是话题，而是"我的认知画像"
5. **壁垒极深**：数据积累越多画像越准，用户迁移成本递增

### 话题来源方案

不需要静态题库。用户已配置的 AI 模型就是最好的话题引擎：
- 取 today 日期作为 seed
- 用最便宜的小模型生成个性化话题（结合用户历史兴趣关键词）
- 成本 ≈ 0.001 元/次，忽略不计
- 内置 100 个经典辩题 JSON 做离线 fallback

### 实现路径

在每日一辩基础上 +1 周：
- `cognitiveStore.ts`：维护认知维度滑动均值（IndexedDB）
- 每次互动后小模型做"认知标注"（从用户回答提取思维特征）
- 月度报告模板渲染（纯前端）
- 认知雷达图 + 趋势折线图

### 完整产品叙事

> **每天 3 分钟辩论 → 累积认知画像 → 月度进化报告 → "我在变聪明"**

**无后端**：✅ 完全纯前端（IndexedDB + 本地通知 + 前端图表渲染）
