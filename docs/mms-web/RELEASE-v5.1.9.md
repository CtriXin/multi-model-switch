# v5.1.9 Preview · 失败会话接续

- 会话下方新增「接续工作」：不依赖旧模型，读取本地历史摘录与原生日志定位，编辑或复制接续资料。
- 可以选模型继续原会话，也可以选择文件夹与模型，准备干净的新会话草稿；发送后才开始，保留原会话和普通草稿。
- 模型连续失败或自动重试耗尽时提示接续；成功后清除旧失败提示。终端里的 error-only 消息现在可见。
- 接续资料保留未执行、取消与结果待确认的状态，限制摘录长度并脱敏。日志路径不会自动作为附件载入；换会话不保证解决上游连接故障。

验证：真实 Pi + 本地 provider 的新会话隔离/原日志不变测试，CLI/RPC/API/草稿/focus 回归和独立审查。发布门禁与 browser 证据保留在原 Stride task 06c34adbc68845ca。

## 升级须知

更新前请先完成或停止正在执行、等待确认与排队的任务。没有模型、通道或 API Key 迁移；更新保留已有会话与备份。接续资料中的历史完成声明仍需核对，发送前确认旧终端已经停止。
