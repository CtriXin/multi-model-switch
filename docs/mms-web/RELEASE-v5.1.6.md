# v5.1.6 Preview · 模型选择、焦点与定时交互修复

- Bot 顶部可以直接搜索并选择模型，下一轮生效；选回当前模型会取消待生效切换。
- 模型和 effort 操作等待实际保存结果，失败保留选择器并提示；effort 与 Fleet 模型菜单支持方向键、Home/End、Enter 和 Escape。
- Bot 设定按 Escape、点击外部或切换面板均保留未保存确认；嵌套窗口逐层关闭。模型/帮助搜索、自定义偏好和资料标题可直接输入，关闭窗口返回入口。
- Fleet 家族选择和模型菜单拆分，显式只选一家时先提示并保留草稿；执行权限与 worker 边界不变。
- 移动端主要 Bot 控件扩大点击区；空定时列表提供创建入口，晚间快捷时间正确显示今晚/明晚。
- Bot 模型窗口明确 effort 跟随 MMS 默认，隐藏不影响 Bot 的 Web 默认 effort。

## 升级须知

常规 Preview 修复，无新配置或数据迁移。Stable 共享修复另发 v4.23.3；本版本仍属于 5.x Preview。
