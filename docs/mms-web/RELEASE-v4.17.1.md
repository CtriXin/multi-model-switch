# v4.17.1 · 现有安装也能看到「更新内容」

- **What's New 面板对现有安装不再静默跳过**（#218）：4.17.0 的规则把「没记过版本」当成「全新安装」。但每一台从旧版本升上来的机器都没记过版本，因为记录这件事是 4.17.0 才有的。结果是所有现在在用的安装升到 4.17.0 后都看不到面板，要等下一版才第一次看见。
- 判断改到服务端：一个连 preferences 文件都没有的 state root 从来没被人用过，第一次读的时候盖上当前版本。等浏览器看到时，空值只可能意味着一次真实升级。
- 之所以不能在前端判断：引导本身会在首次运行时写同一个文件，谁先读谁后写会改变答案。

## 升级须知

- 本次只改 Pilot 前端和一个状态文件的读取，不涉及启动链路、通道配置或模型解析。
- 升上来之后首页会显示一次 4.17.1 的更新内容，点「知道了」即可。
