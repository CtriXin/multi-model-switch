# v4.23.8 Stable · 运行模块归入 lib/

79 个根目录 Python 模块移至 lib/，仓库根目录从 121 项减至约 43 项。CLI、Pilot 与安装器按新目录启动；覆盖安装按精确文件名清理发行版旧模块，保留用户自建文件。模型选择、路由与已有配置语义保持不变，包含 4.23.7 的默认 Effort 即时刷新修复。

## 升级须知

此版本改变安装目录布局，旧平铺布局不再支持。从 4.23.7 或更早版本升级，请先完成或停止正在执行、等待确认及排队的任务，退出 Pilot 后重新运行安装器；旧版 Pilot 的应用内更新器无法完成这次目录迁移。

```bash
curl -fsSL https://raw.githubusercontent.com/CtriXin/multi-model-switch/main/install.sh | bash
```

缺少 lib/ 时，入口会显示重新安装引导并退出；新旧布局混用时，Pilot 更新中心会要求重新安装。安装不要求迁移模型、通道或 API Key，不以全局账号作为回退。

- 升级准备与落盘阶段都会拒绝缺少 `lib/` 的旧发布包，防止跨线更新或缓存旧 Preview 包形成混合安装；拒绝发生在停止会话与切换安装之前。
