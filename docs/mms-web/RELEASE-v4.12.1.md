# v4.12.1 · 首页两栏布局与拉取模型修复

- **首页输入框与「最近」列表**（#174）：输入框随输入内容长高，手动拖过的高度不再被覆盖；拖高到挡住列表时页面切成两栏，「最近」移到右侧，标题固定在顶部。会话计数成为进入全部会话的入口，模型选择器合成一个面。
- **拉取模型不再无故变灰**（#175）：有 approved bundle 的配置根里，从未显式设置 `models_endpoint` 的通道此前在模型页被当成手工目录；现在与 CLI、发布 plan 一致按 `/models` 处理，显式 `manual` 的通道不受影响。

本版本不主动终止正在运行的会话或任务。版本源、Web package metadata 和静态 Web bundle 同步为 `4.12.1`。
