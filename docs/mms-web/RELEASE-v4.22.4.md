# v4.22.4 · 收起的旁问卡片不会自己弹回来

## 升级须知

稳定线的常规版本。没有新的配置项,没有数据迁移,不清空配置或会话历史。

**从这一版起,4.22.x 每个迭代点各自一个版本号**,不再把一批改动攒进一个版本。所以这一版只有一件事。

## 修复

**旁问(/btw)卡片收起之后,它就是收起的。** 以前切一次会话、刷新一次页面、或者从设置页跳回对话,所有收起过的卡片都会弹回展开状态 —— 一屏旁问记录挤在对话里,每次回来都要重新收一遍。

现在折叠状态会被记住,跨会话切换、跨刷新、跨路由跳转都保持。

顺带定清了一件事:**"已处置"的意思是你亲手把它收起来了**,不是"它恰好跑完了"。所以一张自己完成的卡片不会因为运行结束就被当成你看过了;反过来,你收起的卡片也不会因为它还在生成中就被重新展开。

## 从这里去 5.x

打开 Pilot 的「版本与更新」,把更新通道选成 `5.x 预览版`,检查更新,确认升级。5.x 是预览线,带 Bot 工作台,还在打磨。不想留在那边就把通道选回 `4.x 稳定版`。

两条线在同一台机器上不能共存,但配置、通道和会话历史都在同一个 config root(`~/.config/mms-next`)里,来回切不会清空它们。
