# v5.1.8 Preview · 修复开启远程访问时的升级检查

- 升级守护进程现在使用当前 Pilot 会话目录的访问凭证，正确验证新版启动、提交升级和回退。修复服务已经启动却被误判为“自动恢复未完成”的问题。
- 本机升级请求绕过环境代理并拒绝重定向；不会借用其他服务的凭证，也不会关闭 HTTP 认证。
- 新增真实 HTTP 认证下的守护进程入口回归，覆盖远程访问与仅本机访问。

## 升级须知

旧版升级器在开启“让手机或另一台电脑访问”时不能自动取得本次修复。首次升级前，请在本机暂时关闭该开关，升级完成后再开启；或使用安装器更新。升级期间请先完成正在执行、等待确认和排队的任务。

没有模型、通道或 API Key 迁移。更新保留会话与备份；本版本仍属于 Preview 通道。
