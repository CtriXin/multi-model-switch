# MMS Pilot v4.6.0

第一次使用先完成连接，再学聊天。没有通道时自动打开分步表单，已有通道暂时不可用时打开设置查看原因，避免先看到无法操作的教程。

- 服务地址、API Key 分步填写；名称自动生成，协议放在可选设置里。
- 错误 Key 留在当前步骤；返回修改保留输入和模型选择，暂时没有服务信息可稍后配置。
- 选好模型后预览保存，自动读取 MMS 随版本提供的模型预设，首次无需逐项调整 effort、上下文或识图参数。
- 预设就绪后再进入悬浮聊天教程，跳过已经完成的连接步骤；示例先填入草稿，用户发送才调用模型。
- 适配窄屏、深浅主题与放大字号；已有会话、草稿和配置来源保留。

升级保护说明已补齐：数据保留与进程不中断是两件事。当前重启服务会结束 Pi 子进程，之后可以从同一会话继续发送；执行中无缝升级尚未实现，升级前应等任务结束，并保留原数据目录和运行快照。后台自动升级未纳入本版。
