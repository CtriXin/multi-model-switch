# MMS Pilot v4.4.0 · 功能与设计整合

本版整合 PR #114 的模型能力、侧栏与设计更新，以及 PR #120 的简化安装；保留 v4.1 的成果预览、v4.2 的项目资料和 v4.3 的悬浮引导。

## 更容易开始使用

- 安装去掉可选工具包的逐项问答，默认中文并补齐 PATH。检测并复用已有 CLI，Pi 是 Web 必需运行时；安装结束可选择打开页面。
- Web 使用自己的配置空间，新用户可以直接连接模型服务。重复启动只复用相同安装、配置与版本的实例，其他实例占用端口时另选端口。
- 客户端统一命名 **MMS Pilot**，Mac Finder 启动入口同步更名。Logo 旁和设置顶部显示服务实际版本。
- 安装入口见[安装与使用指南](GETTING-STARTED.md)。旧安装器的 main 地址尚不包含这次精简，指南使用本版安装器入口。

## 模型、工作空间与会话

- 新增批量填入模型能力：使用本地快照、OpenRouter 目录或仓库覆盖数据，先填入草稿，再检查并保存；联网目录不等于模型厂商官方数据。
- 模型识图能力使用统一来源，可在设置中编辑识图、上下文长度和长期默认 effort，并先预览再应用。
- 热切模型同步识图辅助工具和运行环境中的模型信息。支持图片的模型切到纯文本模型、再切回来，以及重启恢复，都跟随实际选择。
- 工作空间支持重命名、排序、移除、复制路径和快速新建会话。移除只从侧栏隐藏，原会话与文件引用继续可用；重新添加会恢复原身份。
- 会话菜单支持复制 ID、重命名、分支、导出和归档；列表补充时间、分页与稳定的悬停操作区。

## 更统一的页面与引导

- 设置改为弹窗，关闭后回到当前会话；模型和通道分栏浏览。
- 跟随系统的深浅主题、五种强调色、界面/代码/中文字体、字号与粗体可调整。旧蓝色和玫红偏好会迁移到新色系。
- 字号设置覆盖对话、设置、引导与侧栏；窄屏和大字号下按钮可换行。模型品牌图标、间距、焦点和过渡样式统一。
- 可选“选择即复制”，只处理对话文本，避免复制设置或输入框内容。
- 悬浮引导继续贴着真实控件，适配新的设置弹窗与侧栏；连接弹窗出现时暂时让出操作，关闭后继续。随时点 `?` 可重开或查说明。
- 安装可附带 Fira Code / JetBrains Mono 字体；已保留字体及模型图标的许可说明。

## 修复与边界

- 修复模型切换后辅助工具/环境元数据仍停留旧模型、移除工作空间影响旧会话、设置覆盖当前会话和引导被弹窗遮住等问题。
- 退役工具清理只备份明确由 MMS 管理的入口；不按同名文件或通用标记删除全局 hooks、MCP 配置及用户工具。
- 模型在回答中自称什么仍不能证明实际身份；应查看运行详情、请求路由与会话模型记录。本版没有改变第三方服务的模型映射。
- 多 harness 尚未接入；当前 Web 仍通过 Pi 执行。真实 MMS 配置的人工作业边界保持不变。
