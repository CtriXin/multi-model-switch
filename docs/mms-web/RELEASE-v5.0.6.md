# v5.0.6 · 思考强度挪到了输入框底下

## 升级须知

5.x 是预览线,Bot 工作台仍在打磨。这一版只有一个迭代点,没有新的配置项,不清空配置或会话历史。你之前设过的思考强度会原样保留。

## 新增

**改思考强度不用再翻进模型弹窗了。** 以前要点三次:打开模型弹窗 → 点「高级选项」→ 才看到那个下拉。现在它常驻在输入框底栏、模型选择器右边,**一眼能看到当前是哪一档**(比如 `🧠 思考 · 深入`),点一下就换。

配套的几件事:

- **不支持思考强度的模型,这个控件直接不出现**,不占位置。
- **任务正在跑的时候它是灰的**,免得改了一半的配置漂进正在执行的这一轮。
- **窄屏(手机)会收起前缀文字**,只留图标和档位名。
- 换模型之后思考强度可以单独调,两者互不干扰。

## 修复

**存着一个当前通道不支持的档位时,界面会说清楚,而且不会偷偷发出去。**

如果你给某个模型设过 `max`,后来换到一个不支持 `max` 的通道,以前的表现是:按钮上照样写着「最高」,菜单里却根本没有这一项,一项都不高亮,没有任何提示 —— 而这个值仍然被发给了启动器。

现在按钮会写「此通道不支持 max,请重选」,菜单顶部有一条高亮的告警项,并且**这个值不会被下发**。

**可以退回「跟随 MMS 默认」了。** 菜单第一项就是它,选中之后这个模型的思考强度回到跟随 MMS 配置,换模型时也会继承新模型的默认值。

**新手引导不会再指着一个不存在的控件。** 用不支持思考强度的模型走引导时,那一步会被跳过(总步数从 7 变 6),而不是打开一个和它无关的模型弹窗、同时叫你去看「模型右侧的思考强度」。
