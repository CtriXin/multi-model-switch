# v5.1.4 Preview · 确认更新变成单独一步,不用再往下找

## 升级须知

预览线的常规版本。没有新的配置项,没有数据迁移,不清空配置或会话历史。

## 改进

**点「更新到 …」之后,整个面板换成确认这一步。**

以前确认卡是**追加在更新说明下面**的。说明一长,你点完按钮看不到任何变化,得自己往下滚才能找到那张卡 —— 一次二次确认,读起来不像二次确认。

现在点下去之后面板整页切到确认步:升级须知、安装地址和命令、是否重启空闲会话,都在这一屏里。标题栏和底部按钮固定,确认按钮始终在视野里;进入这一步会自动滚到顶部,返回则回到更新说明原来的位置。也不再套第二层弹窗。

## 从这里回 4.x

**注意方向性**:4.x → 5.x 可以在 Pilot 里走完;**5.x → 4.x 现在不行** —— 应用内更新只安装比当前更高的版本,所以在 5.x 上把通道选回 `4.x 稳定版` 不会自动降级,要重跑安装器并指定 stable 通道。

两条线在同一台机器上不能共存,但配置、通道和会话历史都在同一个 config root(`~/.config/mms-next`)里,来回切不会清空它们。
