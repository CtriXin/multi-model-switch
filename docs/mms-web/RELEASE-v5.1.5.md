# v5.1.5 Preview · 手机上的弹出菜单不再跑到屏幕外

## 升级须知

预览线的常规版本。没有新的配置项,没有数据迁移,不清空配置或会话历史。

## 修复

**手机上点「…」或模型菜单,面板不再伸出屏幕挡住对话。**

以前弹出面板是按触发按钮**右对齐**的。在电脑上没问题,但手机屏幕窄,触发按钮又常在左边,面板就会整个甩出屏幕右侧 —— 你看到的是半张卡压在对话上,想点的选项在看不见的地方。微信内置浏览器里尤其明显。

现在窄屏上它改成从底部升起的一张贴底卡片,宽度按屏幕夹紧,该露的全露出来。宽屏行为不变,仍然贴着触发器,但也会被夹在屏幕内。

**键盘弹出来之后,输入框不再被顶到键盘下面。**

浏览器报的 `100dvh` 在键盘弹出时仍然把键盘那块算在里面,于是输入框被推到看不见的地方 —— 你在打字,但看不到自己打的字。现在页面跟着真实可视区域走,键盘和内置浏览器工具条占掉的高度都会被让开。

## 从这里回 4.x

**注意方向性**:4.x → 5.x 可以在 Pilot 里走完;**5.x → 4.x 现在不行** —— 应用内更新只安装比当前更高的版本,要重跑安装器并指定 stable 通道。4.23.2 起,Pilot 会在你选回稳定版时把这条路直接给你。

两条线在同一台机器上不能共存,但配置、通道和会话历史都在同一个 config root(`~/.config/mms-next`)里,来回切不会清空它们。
