# v5.1.3 Preview · 侧栏那个版本号,现在点得动

## 升级须知

预览线的常规版本。没有新的配置项,没有数据迁移,不清空配置或会话历史。

## 改进

**点侧栏 logo 旁边的版本号,直接打开「版本与更新」。**

以前那个版本号是包在「回首页」按钮**里面**的 —— 一个按钮套着另一个按钮。你想看版本,点下去回了首页。设置页里同一个版本号本来就能打开更新面板,侧栏这个却不能,两处行为不一致。

现在版本号从首页按钮里拆出来,单独可点,打开的是同一个「版本与更新」面板 —— 不是另开一个页面。有新版的时候也和设置里一样带一个提示点。

## 从这里回 4.x

**注意方向性**:4.x → 5.x 可以在 Pilot 里走完;**5.x → 4.x 现在不行** —— 应用内更新只安装比当前更高的版本,所以在 5.x 上把通道选回 `4.x 稳定版` 不会自动降级,要重跑安装器并指定 stable 通道。此前的发布说明把这条说成双向可逆,那是不准确的,已在跟进修正。

两条线在同一台机器上不能共存,但配置、通道和会话历史都在同一个 config root(`~/.config/mms-next`)里,来回切不会清空它们。
