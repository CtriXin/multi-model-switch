# v4.15.0 · 更新会换掉整套安装；`mms web` 有帮助页

- **更新同时换掉命令行和 Pilot**（#195）：以前在页面里点更新，只有网页服务换了版本，`mms` / `mmf` 还停在上次安装的版本，两边一直漂。现在新版通过启动与应答验证之后，同一份代码会写进当前安装目录，三个入口从此同版本。写入前逐项备份，任何一步失败就整体还原，网页仍按暂存副本运行。源码检出不会被写，确认页会说明原因。
- **更新前先说清代价**（#195）：点「更新到 vX」之后多一步确认，写明更新后的地址和端口、命令行是否一起更新、是否重启空闲会话，以及该版本发布说明里 `## 升级须知` 一节的原文。发布说明没有这一节，就表示这个版本没有需要提前知道的代价。
- **更新完成后页面自动刷新**（#195）：不再需要找到那个只在对话框里出现的刷新按钮。输入框草稿是持久化的，刷新不会丢。
- **安装脚本回到原端口**（#195）：以前它停掉旧 Pilot 后从 8765 重新找空闲端口，原本在别的端口上的实例会被搬走，已打开的页面和已发出去的链接全部作废。同时会清掉上一次页面更新留下的暂存版本指针，这曾经让重装看起来对网页端毫无效果。
- **`mms web` 帮助页**（#192）：不带子命令直接输入 `mms web` 会列出 `start` / `status` / `url` / `stop` / `restart`、常用例子和可用选项，不再占住终端起服务；带 `--open` 等选项时行为不变。
- **修复** ：补上 v4.14.0 里两条与实测档位不一致的测试断言（#196）。

## 升级须知

- 不带任何参数的 `mms web` 从「前台启动服务」改成「打印帮助」。要前台启动请用 `mms web --open`，要后台启动请用 `mms web start`。`MMS Pilot.command` 和安装脚本都带参数，不受影响。
- 本次更新会同时替换安装目录里的 `mms`、`mmf` 和 Pilot。如果你正在同一台机器上用 `mms` 跑别的会话，建议等它结束再更新。
- 从开发检出（git 工作树）运行的 Pilot 不会被更新替换，确认页会写明；那种情况请用 git 更新命令行。
