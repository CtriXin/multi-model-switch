# v4.18.0 · 拖进来的文件夹会自己找回路径

## 拖文件夹进 Pilot，它自己找到那个目录

- **浏览器交出来的只有文件夹名字和里面有什么**（#182）：Pilot 现在拿这两样去本机找回真实路径 —— 先看已知工作目录和它们的邻居，再问系统索引和 zoxide，最后做一次有预算的扫描。找到唯一一个、而且里面的东西对得上，就直接用；对不上或者有多个，就让你挑。
- **搜索没搜完的时候，不会假装确定**：扫描有目录预算和时间上限，系统索引和候选列表也有行数上限。任何一处截断都意味着有地方没看过，可能恰好就是你拖进来的那个。这种情况下候选照常列出来，但不会替你决定。
- **找文件夹不再冻住整个 Pilot**：这些搜索之前跑在全局写锁里，一次拖拽会让发消息、停会话、确认更新一起排队几秒；原生文件夹选择器更是对话框开多久就锁多久。现在这三条只读路由跑在锁外面。

## 升级须知

- 本次会替换安装目录里的 `mms`、`mmf` 和 Pilot。如果同机有 `mms` 会话在跑，建议等它结束再更新。
- 更新过程中 Pilot 会重启，页面会自动刷新；重启期间已在跑的网页会话会短暂断开。
- 拖入文件夹会在本机做一次有上限的目录扫描（最多两秒），只读不写。不想用就照旧手动选文件夹。
