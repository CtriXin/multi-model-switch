# v4.23.2 · 装了 5.x 又想回来的人,现在能看到路了

## 升级须知

稳定线的常规版本。没有新的配置项,没有数据迁移,不清空配置或会话历史。

## 修复

**一台跑着 5.x 的机器,把更新通道选回「4.x 稳定版」之后,不再被告知「已是最新 4.x 稳定版」。**

这句话是假的 —— 那台机器跑的是 5.x。而弹窗顶部明明写着「当前版本 v5.x」,两句话放在一起也没有任何提示说它们矛盾。真实情况是:Pilot 的应用内更新**只安装比当前更高的版本**,所以在 5.x 上看 4.x,它既不是"有更新"也不是"已最新",而是**根本不在这条线上**。

现在它就这么说,并且给出真正的出路:一段可以直接复制的安装器命令,以及一条先备份的提醒 —— `~/.local/share/mms-web` 里的 Bot 工作台、定时任务和记忆,4.x 读不了,降级前请自己留一份。

**没有做一键降级**,这是有意的:代码换回 4.x 之后没有任何东西会去读、迁移或警告那些 5.x 写下的数据,静默降级只会把它们变成孤儿。

## 勘误

4.22.3 的发布说明和更新日志此前都写着「选回稳定版就继续留在稳定线,随时可逆」。**那是不准确的**,两处都已更正为:方向不对称 —— 4.x → 5.x 能在 Pilot 里走完,5.x → 4.x 要重跑安装器带 `--channel stable`。

这条错误的承诺正是机主自己升到 5.x 之后找不到回头路的原因。

## 从这里去 5.x

打开 Pilot 的「版本与更新」,把更新通道选成 `5.x 预览版`,检查更新,确认升级。5.x 是预览线,带 Bot 工作台,还在打磨。回来的路见上面。

两条线在同一台机器上不能共存,但配置、通道和会话历史都在同一个 config root(`~/.config/mms-next`)里,来回切不会清空它们。
