# v4.11.0 · 统一配置根与入口一致性

- **统一配置根**：`mms`、`mmf`、`mmg` 和 Pilot 默认共用 `~/.config/mms-next`，避免旧版稳定入口与 dev/Pilot 各自读取不同通道，导致模型显示不可用。
- **兼容旧安装**：显式固定为 stable 的旧 `~/.config/mms` 通道仍可读取；升级会识别既有安装元数据，不覆盖旧根，也不会把旧会话或凭据迁移到错误位置。
- **首次使用可继续**：空白用户首次运行会进入受控 bootstrap，已有稳定配置可作为只读来源导入；Web 配置通过 Registry reviewed plan 发布，CLI 与 Pilot 读取同一份结果。
- **入口保护**：Web 自有配置根可写，legacy stable 根继续保持 human-gated，防止浏览器配置意外改写稳定环境。

本版本不主动终止正在运行的会话或任务；配置根迁移仅影响后续入口解析与新配置发布。版本源、Web build manifest 和静态资源已同步为 `4.11.0`。
