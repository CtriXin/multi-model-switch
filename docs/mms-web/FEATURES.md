# MMS Web：功能与交互边界

2026-09-08。本地真实 Pi Web 迭代，尚未公开发布。Web 为新增入口，复用 MMS 的模型解析、选中通道、隔离与原 launcher。

## 已实现

| 使用动作 | 当前行为 |
|---|---|
| 开始工作 | 选工作文件夹、模型及独立通道；首条消息前选择真实支持的 effort，默认继承 MMS 生效偏好；可选择执行或只读规划 |
| Skills | 新会话与续聊按当前 workspace 搜索、多选；`/skill:name` 补全；实际内容随消息送入 Pi，遵守 MMS 共享/项目加载顺序 |
| 首次连接 | 在独立配置中填写地址与 Key → 拉取或手填模型 → 搜索勾选 → 脱敏预览保存 → 查看真实支持的 effort；取消/返回清除临时 Key，配置冲突可返回重新预览 |
| 模型库 | 同名模型分组，展开不同通道；显示原 Pi 模型输入/上下文/协议/effort；收藏、通道备注、Web 首选通道与默认 effort 保存当前浏览器 |
| 运行状态 | 侧栏、顶部和输入区同步显示本轮已完成、执行、思考、回复、工具、压缩、重试、等待回答及异常；实际新产出保留新回复提示，查看结果后清除未读；动画跟随实际 Pi 事件，支持减弱动画与断连静态提示 |
| 看执行过程 | 流式回复、提供方实际返回的 Thinking（可展开）、工具参数和结果、工具图片、错误和原生 confirm/select/input/editor 交互 |
| 文件夹与资料 | 会话按 workspace 分组并可折叠，记住展开状态；目录逐级浏览、文本/Markdown/图片预览、Git 文本差异、@ 文件引用 |
| 本地文件 | 系统文件选择器、粘贴绝对路径或 file:// 路径，直接引用原文件；图片缩略预览、移除、草稿恢复；Pi 按原路径读取，无复制和上传大小门槛；无原路径的剪贴板图片另行保存 |
| 消息控制 | 停止当前工作；工作中追加消息进入 follow-up 队列，查看和清空待发送队列 |
| 会话管理 | 重命名、归档/恢复、整段或指定回复处分支、消息复制、Markdown 导出；浏览器刷新与进程重启后继续原上下文 |
| 运行参数 | Thinking、自动压缩、立即压缩（支持附加保留要求）、失败自动重试；查看模型/协议、上下文占比、Token、缓存和脱敏进程信息 |
| 任务模板 | 导出首条任务说明、模型偏好和规划开关；接收方导入后选择自己的模型服务和文件夹，检查草稿再发送 |
| 阅读与操作 | 连续工具分组与命令/路径摘要；同轮身份合并；消息操作 hover/focus；提问刻度 hover 展开、点击定位和回到最新；Markdown、代码复制、附件放大；斜线命令、浅深色和四种强调色、窄屏导航 |
| 草稿 | 普通新任务与会话草稿保留 7 天，刷新恢复文字、Skills、引用和附件；图片缩略图从本地服务恢复，失效附件明确报错 |

等待回答只计入执行工具明确发起的问题，运行异常单独列出。进程 idle 不是错误；已归档会话可恢复。

### Commands

`/help`、`/files`、`/plan on|off`、`/thinking LEVEL`、`/compact [保留要求]`、`/clear-queue`、`/name 新名称`、`/fork`、`/export`。输入 `/` 展示可用命令，方向键选择，Tab/Enter 补全，参数后 Enter 执行。Pi 当前安装的扩展命令动态列出；不支持的命令明确报错。

### MMS 自有价值

模型与通道组合仍由 MMS 解析，不另建一套账号或 fallback 规则。运行详情把所选服务、通道、协议和原生缓存数据放在同一处。任务模板只表达工作意图和模型偏好，不携带结构化凭据、服务地址、本机目录、附件或完整会话；接收方使用自己的 MMS 配置。任务说明是导出者自己选择分享的文字，可能包含其输入的业务资料，应在分享前自行检查。

## 限制与尚未追齐的部分

- 真实 `~/.config/mms*` 仍只读接入，新 Web 尚未对接这份配置的编辑与 Registry 发布链。首次连接向导支持独立配置；已有 Registry 的修改仍应由 MMF Config Web 完成。
- 当前原生 Web harness 为 Pi。不是 Claude/Codex/Kimi CLI 的通用适配器，也没有自动导入 Glint 或全部 mmf 历史。
- Thinking 只展示上游实际提供的内容；模型未提供时不制造思考文本。用量来自 Pi，费用不是供应商实际账单。
- 普通本地文件引用无上传大小限制，不读入提示全文；仅保存原路径元数据，原文件改变后读取最新内容，原文件移动/删除则明确提示重新选择。图片预览最多读取 8 MB，较大图片仍可引用；文本预览最多读取 64 KiB。普通浏览器拖拽未提供原路径时，引导系统选择或粘贴路径，不猜测路径、不自动复制。系统文件选择器目前适配 macOS，其他系统可粘贴路径。剪贴板截图没有可用原文件路径，仍保存为附件，支持 PNG/JPEG/GIF/WebP、每个 8 MB。旧上传附件保留兼容。每条消息最多 8 个文件及 20 个 workspace 引用。PDF/Office 的 Web 内容解析尚未实现，但可把本地原路径交给 harness 的工具处理。
- 当前会话运行参数可调，跨模型/服务切换需新建会话。完整 Kimi parity 仍缺会话全文搜索、批量会话操作、子代理/结构化 Todo 专用展示等；不把本版称为全量追平 Kimi。
- 文件浏览和 diff 只读；隐藏文件、凭据、越界 symlink 和依赖目录过滤。没有直接编辑文件、提交 Git 或发布预览站点的按钮。
- 分支创建独立原生对话历史，工作文件夹仍共用，不等于 Git worktree 隔离。
- 只读规划由 Web 附加的 Pi extension 在 tool_call 上拦截写入/shell/其他工具，允许 read/grep/find/ls；默认关闭。它不是 OS sandbox，也不改变普通 mmf 的工具权限。
- 本地 HTTP 仅监听 127.0.0.1。开发启动需要现有 Pi/Node/Python 与前端构建；尚无面向普通用户的安装更新包、云端分享会话或公开 Release。

### 通道模型与默认值

设置 → 模型与通道 → 管理通道模型：支持现有通道拉取模型、搜索、手工补充、勾选可用模型和保存 MMF 默认 effort。保存前展示明确变更，注明同名模型跨通道影响。拉取不会自动更新已批准目录。

当前 effort 编辑以 Web 使用的 Pi 路由能力为准；不支持 Pi 或仍由旧版 model-policy.json 显式覆盖的项保留来源提示，不伪装成可写配置。连接 Key/地址的完整编辑、其他 harness 专属默认值和恢复为自动等高级操作继续保留在原配置工具，后续按常用程度整合。

2026-09-08 常用配置收尾：现有通道 URL/Key 可在同一模型设置页编辑并预览；模型列表连接检查与生成验证明确区分；默认 effort 支持恢复自动。已通过隔离配置/原生 Pi、浏览器和真实目录副本验证；当前本地 Web 已加载，真实 MMF 配置未由 agent 写入。后续方向与未实现能力见 `HARNESS-DIRECTION.md`。

### 模型能力与侧栏工作区（issue #112）

通道模型页新增能力列：可接收图片、上下文长度可直接编辑，与默认 effort 走同一条预览确认写入通道。每行显示这两个值的来源，区分「你设置的」「通道预设」「MMF 目录」和「未声明，按保守值」。

这里设置的识图能力现在是全局真值。`_pi_model_input_types()` 把用户设置排在最前，其次是 Pi 实测硬编码、provider profile 与 approved 目录，最后才是名称匹配兜底。给某个模型打开识图后，它在任意 harness 都自己读图；关闭后由辅助模型中转。完整顺序与禁止事项见 `docs/AGENT_GUARDRAILS.md` 的 Vision Capability Single Truth。

Pi 的图片中转没有内置模型名单。候选池是当前通道里能力判定为能读图的模型，跟着你的配置走；识图时从池子里随机取，失败再换下一个。主模型自己能读图时不注册中转工具，池子为空时 launcher 打印明确提示，不静默降级。唯一开关是 `config.toml` 的 `[vision_sidecar] enabled`。

侧栏工作区区域 hover 出现收起/展开全部，以及排序菜单（手动排序、按最后编辑时间）。每个文件夹 hover 出现操作菜单（复制路径、重命名、移除工作区，手动排序时另有上移下移）和在该目录新建会话。排序、顺序和折叠状态保存在当前浏览器。重命名只改显示名称，移除只从侧栏移除，文件夹、文件和会话都保留，会话移到「其他工作空间」分组仍可打开和搜索；启动目录不可移除。
