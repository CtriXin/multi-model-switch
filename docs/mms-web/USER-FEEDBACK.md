# 自愿体验反馈

反馈入口连接飞书原生公开填写表单，回答保存在维护者的私有 Base；不需要另建接收服务器，也不在 MMS 中分发飞书凭据。表单已配置为 `anyone`、`allow_anonymous=true`、`require_login=false`，Base 数据链接保持 `closed`。

当前验收：已通过真实 form-submit 写入并由维护者 API 回读测试记录；该提交使用 CLI 用户认证，只证明接收链路。匿名浏览器完整提交仍待验，不能以配置或 CLI 成功代替。发布前须补齐这一项。

## 低打扰邀请

从安装带此功能的版本以后开始计数，不扫描历史对话。只有本地服务接受的 Pilot 首条/后续请求、Bot 直派/自动分流/追问才计数。定时任务、peer 分发、打开页面、轮询、工具调用和重复 requestId 不计数。

同时满足以下条件才有资格：

- 至少 3 个 UTC 使用日，首次使用已过去 72 小时。
- 至少 6 次使用：与前次主动请求相隔至少 30 分钟才算新一次。
- 至少 12 次主动请求，最后一次已过去 60 秒。
- 表单地址启用；本机所有会话和 Bot 均没有正在执行/等待处理的任务。
- 页面在前台，30 秒内未键盘输入或点击，没有草稿、弹窗、设置、引导或更新操作。

只显示一条内联邀请，不自动打开表单、不抢焦点、不发送桌面通知。多个标签页共享领取状态，刷新和版本升级不重置。

第一次显示即记为已邀请；只有明确选择「以后再说」才允许 14 天后的第二次，最多两次。关闭页面、打开反馈表单或选择「不再提醒」后均不再自动邀请。安静的手动入口仍然保留。

`feedback-state.json` 位于本地 Pilot state root。只保存计数、日期、散列后的去重标识及提醒偏好，计数不外传，不保存聊天内容。损坏状态默认停止自动邀请。更换或清除 state root 不属于同一安装。

## 填写与接收

点击入口才在新标签页打开飞书表单，原聊天页面保留。必填仅两题：最近用 MMS 做什么、事情做成没有。使用入口、具体经历、希望 Bot 长期负责的事情、联系方式均选填。不填写联系方式也能提交。

MMS 不自动附带版本、系统、使用计数、对话、代码、路径、provider、账号或 Key。表单提示不要在手写回答中填写私密内容。飞书作为表单托管方处理访问及提交请求；这不等于平台层面无任何访问日志。

MMS 只记录「已打开」，不记录或宣称「已收到」。实际提交、错误和成功提示由飞书表单负责。打开后未填完也不会再自动催促；维护者在私有 Base 查看真实回答。未留联系方式的反馈不能用于主动联系该用户。

## 维护与回滚

`DEFAULT_FORM_URL` 为公开的填写链接，不是 Base 数据链接。部署环境可以用 `MMS_FEEDBACK_FORM_URL` 更换 HTTPS 表单，设为空值可隐藏入口和邀请；无须修改用户的 MMS 配置文件。只接受无凭据、无 fragment 的 HTTPS URL。

关闭飞书分享会停止接收，但不会自动隐藏已经安装的客户端入口；停用时须同时配置空值或发布停用变更。表单问题、分享权限及 CLI 兼容性证据留在原 Stride task。客户端不需要 lark-cli。

反馈只解释愿意回复者的经历，不代表全体活跃用户或流失率；此功能不提供远程使用遥测。
