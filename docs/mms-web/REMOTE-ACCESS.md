# 从手机或另一台电脑访问 Pilot

Pilot 默认只听 `127.0.0.1`，只有这台电脑上的浏览器能打开。要让别的设备访问，有两条路，门槛差很多。

设置里的开关只管第一条。第二条需要自己动手，我们不提供支持，但有一条不需要域名、不需要账号的路。

## 一、同一个网络（设置里一个开关）

设置 → 外观与使用 → **让手机或另一台电脑访问**。

打开后：

- 这台电脑会在自己的每个网络地址上各开一个入口，端口和本机那个一样
- 页面列出所有可用地址，并说明各自适用什么设备
- 选一个地址，页面给出带 token 的完整链接和一个二维码
- 手机相机扫码就能打开

关掉后这些入口立刻关闭，网络上再也看不到；本机那个入口不受影响，一直在。开关的状态会记住，重启后保持原样。

### 为什么列出多个地址

一台机器通常有多个地址，各自通向不同的网络：

| 地址形态 | 适用 |
| --- | --- |
| `192.168.*`、`10.*`、`172.16-31.*` | 同一个 Wi-Fi 或网线下的设备 |
| `100.64-127.*` | 装了同一个虚拟网（如 Tailscale）的设备，可以跨网络 |
| 其他 | VPN、Docker 之类的通道端点，不一定通 |

只有你知道另一台设备在哪个网络里，所以页面不替你猜，全都列出来。装了 VPN 的机器上，通往互联网的那个地址往往正是手机连不上的那个。

### token

打开开关时会生成一个 token，存在 `<state-root>/remote-access-token`，权限 `0600`。链接里带上它才能进，没有它一律 401。

- token 在关掉开关后保留，所以关了再开，之前发出去的链接仍然有效
- 「换一个 token」会让之前所有链接和已经打开的页面立刻失效

### 注意

在公司、学校、咖啡馆这类共用网络里打开，同网段的任何人都能碰到这个入口。token 挡得住，但这是要不要开的判断依据。

这条路是普通 `http`，浏览器不把它当安全环境，所以装不了主屏幕图标、用不了相机，剪贴板也受限。要这些能力得走下面第二条。

## 二、出门也要用

上面那个开关只在同一个网络里有效。要在外面用流量访问，需要一条从公网到这台电脑的通道。

原理都是反向连接：这台电脑上跑一个客户端，主动向外建一条长连接，外面的请求顺着它回来。所以**不需要公网 IP，也不用在路由器上开端口**。

设置页里那一行有个「交给 Pilot 配」按钮，会开一条新会话把这件事作为任务交给模型。它会先问你有没有域名、有没有服务器，再按你的情况挑一条，改 DNS 和建账号这类动作每步都要你点头。

四条路，门槛从低到高：

### A. 什么都没有：Cloudflare 快速隧道

```sh
cloudflared tunnel --url http://127.0.0.1:8765
```

不需要账号，不需要域名。跑起来会打印一个 `https://xxx.trycloudflare.com`，立刻可用，而且是 HTTPS。

把它打印的地址整条粘进设置页的**隧道域名**，点添加，立即生效，不用重启 Pilot。这一步是必须的：Pilot 只接受它知道的名字，否则会被 403 挡掉。

代价：

- **每次重启地址都会变**，得重新粘一次
- Cloudflare 把它定位成调试用途，不保证可用性，并且有 200 并发上限
- 它不支持 Server-Sent Events。**Pilot 不受影响**，因为 Pilot 是轮询而不是流式推送

### B. Tailscale 之类的虚拟网

免费，不需要域名，能跨网络。两台设备装同一个账号就行，Pilot 的地址列表里已经会出现那个 `100.x` 地址，标着「装了同一个虚拟网的设备」。

代价：两边都要装客户端并登录。

### C. 自己的域名托管在 Cloudflare：具名隧道

地址固定，可以收藏。前提是一个域名和一个免费 Cloudflare 账号。

1. 装 `cloudflared` 并登录：

   ```sh
   brew install cloudflared      # macOS
   cloudflared tunnel login
   ```

2. 建一条隧道，把域名指向它：

   ```sh
   cloudflared tunnel create pilot
   cloudflared tunnel route dns pilot pilot.你的域名
   ```

3. 让隧道转发到本机的 Pilot 端口：

   ```sh
   cloudflared tunnel run --url http://127.0.0.1:8765 pilot
   ```

4. 把域名加进 Pilot。两种方式都行：设置页的隧道域名字段（立即生效），或者启动时带 `--hostname pilot.你的域名`。

隧道要长期可用得装成系统服务（`cloudflared service install`），否则终端一关就断。

### D. 自己的服务器：反向隧道

有服务器的话，`ssh -R`、frp 之类都能做同一件事，把服务器的某个端口反向映射到本机的 Pilot 端口。同样要把服务器上对外的那个域名加进隧道域名。

### 域名不是秘密

证书一签发就会进公开的 Certificate Transparency 日志，几分钟内就能被扫到。所以 token 依然是唯一的门禁，别把带 token 的链接贴到公开地方。

走 HTTPS 的这几条比局域网那条多出一些能力：可以装主屏幕图标、能用相机、剪贴板不受限。

## 三、给别人用（还没做）

要让不懂配置的用户也能出门访问，需要我们自己提供中继服务器：用户装完就拿到一条能用的链接，不需要域名和 Cloudflare 账号。原理和第二条一样，只是把 Cloudflare 换成我们的机器。流量和维护成本由我们承担，所以这条要单独评估。

## 命令行

```sh
mms-web                                   # 只听本机；或按开关上次的状态
mms-web --listen lan                      # 本机所有网络地址，需要 token
mms-web --listen lan --hostname pilot.x   # 再接受一个隧道域名，只管这一次启动
mms-web --listen all                      # 所有网络接口，包括枚举不到的
```

不带 `--listen` 时，设置里开关的状态说话。带了就以命令行为准，只影响这一次启动。`--listen all` 是明确的选择，界面开关不会去改它。

`--hostname` 给的名字只对这一次启动有效。设置页里加的会记住，重启后仍然接受——快速隧道每次换地址，所以那个字段才是常用入口。
