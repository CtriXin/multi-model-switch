# v4.10.0 · 连接引导与可分享任务

- **从连接到第一条对话都有悬浮引导**：圈亮真实地址、API Key、模型和保存控件；错误留在当前步骤，返回保留填写内容。载入模型预设后再学选项目、模型、effort 和发送。问号可重开；支持窄屏、深色与大字。
- **上下文和 Skills 有实际来源**：运行详情可按消息检查自动规则、可用目录、所选正文加载、明确调用与读取失败，保留来源和版本。普通聊天仍不显示空资料清单；无证据时不猜。
- **任务模板 v2**：目标、示例、变量、Skills 与模型要求；填写后载入草稿，缺条件有明确提示，发送前再次核验。变量/草稿可刷新恢复，兼容 v1；导出前清理已知凭据和本地路径，并显示最终预览。
- **三份即用模板**：整理产品需求、检查项目改动、分析一份数据，补自己的资料即可开始。
- **保留 Claude 的界面更新**：更新说明按 Markdown 显示，工作文件夹名避开操作按钮；有新版才显示顶部更新入口，设置里的版本号随时可检查。

升级沿用安全更新：执行中、待确认、排队或状态未知时等待；先备份，保留会话和成果。默认保留所有活跃 Pi，只有明确允许时才重启空闲可恢复会话。Web 仍由 Pi 执行；npm/npx 本次暂不发布。

安装最新稳定版：

```bash
curl -fsSL https://raw.githubusercontent.com/CtriXin/multi-model-switch/main/install.sh | bash
```

静态清理不能判断所有业务敏感信息，分享前请检查最终模板。Skills 加载/调用记录不保证模型遵循指引；间接工具读取无法可靠归因时明确无证据。
