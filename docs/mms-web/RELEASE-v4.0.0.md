# MMS v4.0.0 — 本地 Web 对话

MMS 现在有真实可执行的本地 Web 客户端。选择工作文件夹、模型和通道后，可以通过原 MMS 启动链使用 Pi，进行连续对话、工具调用和文件操作。原有 CLI 启动能力与隔离方式继续保留。

## 本版内容

- Pi RPC 会话、持续对话、恢复、停止、分支、归档与导出。
- 按模型合并通道选择、收藏、通道备注、模型能力、默认 effort 与本次 effort。
- 模型服务接入、模型拉取、连接测试与配置差异确认。
- Skills、命令提示、工作文件夹展开、本地文件原路径引用、图片预览。
- 工具分组、thinking、执行状态、完成高亮、hover 提问导航、Markdown 阅读与复制。
- 每轮过程折叠、收起/展开全部，以及完成后自动收起设置。
- 会话内切换模型/通道：保留上下文，验证实际 Pi 选择；目标不可用时保留原选择。
- 编译好的 Web 页面随安装分发，增加 `mms web`、`mms-web`、macOS `.command` 入口，以及可选 Pi 安装。

## 安装与升级

按 [安装与使用](GETTING-STARTED.md) 安装指定 tag。默认仅本机访问；对方需要在自己的机器上安装并使用自己的模型服务。

## 明确边界

Web 首版使用 Pi。其他 harness 仍可从 MMS CLI 启动，但尚未接入统一 Web 对话。没有团队远程权限、插件市场或托管模型额度。配置隔离不等于文件系统 sandbox。工作文件按用户选择交给本机 agent 操作。

v4 版本包与 stable/dev/canary 分支晋级分别记录；发布 tag 不改写 `mms/mmf/mmd/mmg/mmm` 的固定通道含义。
