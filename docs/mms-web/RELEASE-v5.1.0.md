# v5.1.0 Preview · 近期功能整合与可靠性修复

本次按明确授权，将近期改动集中校验后提升 minor 版本；后续单个迭代仍沿用 patch 规则。继续使用 5.x Preview 通道。

- 包含 4.23.0 的应用内目录树、registry drift、committee protocol、更新参数与首次运行回归修复，以及稳定线已有的旁问折叠、连接提示、排队取消和更新通道修复。
- 修复稳定线安全响应头合入后 Bot worker 成功响应中断的问题，保留 token 与 cookie 边界。
- Bot 修改定时内容不会重置下一次执行时间或改掉时区。定时记录和任务在启动前一起写盘，写入失败时释放尚未启动的占用，恢复后不会重复派发。
- 修正夏令时重复小时和不可表示的超大定时间隔。
- 计划指定模型的临时会话结束后真正释放子进程，同时保留历史、artifact 和 Bot 主会话。
- 选择当前模型可取消待生效的模型切换；会话中的 effort 只提交当前模型支持的明确档位。
- 侧栏区分未读完成与已读待命；滚到最新回复时持久化已读回执。首次加载没有历史回执的已完成会话仍按既有基线显示待命，该边界保留在设计文档中。
- 助手回复可打开专注阅读，打开后直接 Enter 复制原文，Esc 关闭，输入区草稿保留。

Fleet 和 Grok ACP harness 候选未达到本次就绪标准，不包含在本版。已有 Grok CLI launcher 不受影响。

## 升级须知

保持原有 config root、账号和会话历史。验证覆盖隔离回归、真实本地子进程生命周期和浏览器页面操作；没有真实 provider 调用或 Windows 原生安装验收。
