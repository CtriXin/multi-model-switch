# v4.22.3 · 可以从设置里切到 5.x 预览版了

## 升级须知

稳定线的常规版本。没有新的配置项，没有数据迁移，不清空配置或会话历史。

**这一版才真正带上了通道切换。** 4.22.2 发布之后才合入的功能，装 4.22.2 的人在更新对话框里是看不到那个下拉的。

## 新增

- **更新对话框里可以选通道了。** 「版本与更新」里多一个下拉：`4.x 稳定版` / `5.x 预览版`。选到预览版之后，检查更新会去找 5.x 的最新预览；**选好只是改变它检查什么，升级仍然要你确认**。选回稳定版就继续留在稳定线，随时可逆。两个通道各自缓存检查结果，切回去不会拿到另一条线的答案。

  以前稳定线根本看不到预览线：更新探测读的是 GitHub 的 `releases/latest`，这个端点按定义不返回预览版，而 5.x 的 tag 全是预览版。所以在这一版之前，换线只能从终端重跑安装器。

- **设置里多了「运行环境」标签页。** 宿主平台、路径样式、进程控制、Shell、浏览器能力、会话启动链路、配置模式、模型自动发现、配置与状态目录，集中到一处。这是从 5.x 回流过来的。

## 修复

- **连接不稳定时不再动不动弹红条。** 后台每 8 秒一次的轮询失败一两次不再弹出红色报错；连续失败约 24 秒之后才给一条安静的提示，任何一次成功立刻消失。红色横幅现在只留给你自己的操作失败（比如发送失败），而且仍然带「重新连接」。
- **删掉一条已排队的「引导」，界面会说实话。** 以前不论撤回成没成功，卡片都写「已取消，未执行」。现在撤回成功才这么说；如果 Pi 已经把它取走了，卡片会说清楚这条已经送给模型、删除来晚了。

## 从这里去 5.x

装好这一版之后，打开 Pilot 的「版本与更新」，把更新通道选成 `5.x 预览版`，检查更新，确认升级。5.x 是预览线，带 Bot 工作台，还在打磨。不想留在那边就把通道选回 `4.x 稳定版`。

两条线在同一台机器上不能共存，但配置、通道和会话历史都在同一个 config root（`~/.config/mms-next`）里，来回切不会清空它们。

## 2026-09-17 勘误

上文“选回 4.x 稳定版”只更改更新检查通道。Pilot 仅安装高于当前版本的更新，5.x 降回 4.x 需重跑安装器并带 `--channel stable`；不支持通过该下拉框直接降级。原发布说明保留以供追溯。
