# v4.13.1 · 远程访问开关安全修复

- **`--listen all` 下关闭开关不再清空 token 门禁**（#186）：以 `--listen all` 启动时，主 socket 绑定在所有网卡且不会回收；此前把「让手机或另一台电脑访问」关掉只会清空 token，网络上任何人都能不带 token 访问全部接口。现在该模式下开关不改变状态，token 始终必需。默认的回环模式与设置里打开的局域网模式不受影响。
- **补记**：v4.13.0 已包含 #181「手机与另一台电脑访问：设置里一个开关」与 #167 手机端修复，发布说明当时漏写。

版本源、Web package metadata 和静态 Web bundle 同步为 `4.13.1`。
