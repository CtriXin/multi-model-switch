# v5.1.2 Preview · 同一 Bot 上多方听意见

- 恢复 #295 的“寻求场外帮助”：选择 2 家、3 家或指定家族与型号，听听/问仔细，最后由主 Bot 综合各方结论。
- 固定模型或家族失效时明确提示并停止，不会悄悄换成另一个模型。保留失效项，支持重新选择或恢复自动型号；同名模型显示来源。
- 场外 worker 使用指定模型的新建一次性 Pi session，仅开放 read、grep、find、ls；关闭 shell、写工具和扩展加载，不复用主 Bot 会话，不接受会话续聊、模型切换或分支操作。
- 成功或失败后回收 worker 进程。单个 worker 启动失败不再卡住汇总；分批 worker 的意见不写入共享长期记忆，最终综合仍按主 Bot 的记忆设置保存。
- 保留“先确认计划”的批准/拒绝入口；即时、一次定时和循环日程都记录场外帮助选项，旧日程保持原行为；日程执行采用 Bot 届时的家族与型号设置。
- 保留 v5.1.1 已发布的重命名焦点修复，避免延迟全选覆盖刚输入的文字，并补齐其升级说明。
- 修复窄屏 Bot 列表将聊天输入框挤出可视区域的问题；列表和聊天在同一屏幕高度内分配空间。

## 升级须知

5.x 继续为 Preview。场外帮助会按所选家族并行调用多个模型，产生相应 API 用量；可随时关闭。worker 负责只读意见，主 Bot 仍按用户任务和原有权限综合处理。升级沿用现有配置、账号与主会话，不迁移真实账号；降回 4.x Stable 需使用安装器显式指定 stable。
