# MMS Pilot v4.5.0

## 文件随正文引用

- 拖拽、粘贴截图和选择文件都在正文光标处插入路径，可在多个文件之间说明各自的要求。
- 有原路径时直接引用；浏览器只有文件内容时，自动保存到项目 `.pilot/attachments`，不再要求重新选择本地文件。单个导入文件最大8MB，大文件可引用原路径。
- 复制插入路径即可在同一项目的其他会话继续用。删除草稿路径会取消本轮引用，刷新也不会重新加回；已经保存的文件仍在。

## 按名字找项目

- 点工作文件夹，输入项目名查找已添加的项目，支持键盘选择，记住上次目录。
- 如果已有 zoxide，自动利用它的常用目录记录；没有也能使用，不强制安装、不改 shell 配置。完整路径和浏览文件夹仍可用。
- 悬浮引导与功能说明同步更新。

验证与整合结果在正式发布前补齐。
