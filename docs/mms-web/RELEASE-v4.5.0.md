# MMS Pilot v4.5.0

## 文件随正文引用

- 拖拽、粘贴截图和选择文件都在正文光标处插入路径，可在多个文件之间说明各自的要求。
- 有原路径时直接引用；浏览器只有文件内容时，自动保存到项目 `.pilot/attachments`，不再要求重新选择本地文件。单个导入文件最大8MB，大文件可引用原路径。
- 复制插入路径即可在同一项目的其他会话继续用。删除草稿路径会取消本轮引用，刷新也不会重新加回；已经保存的文件仍在。

## 按名字找项目

- 点工作文件夹，输入项目名查找已添加的项目，支持键盘选择，记住上次目录。
- 如果已有 zoxide，自动利用它的常用目录记录；没有也能使用，不强制安装、不改 shell 配置。完整路径和浏览文件夹仍可用。
- 悬浮引导与功能说明同步更新。

## 模型能力逐项复核（PR #127）

- 按厂商官方资料补齐模型能力，保留 Kimi Code 套餐的保守默认值。新增可追溯的来源索引；不覆盖本机未推送的 profile 工作。
- 「检查最新能力」先展示每个模型、字段、当前值、建议值及来源，选好后填入草稿，再检查并保存。
- 本机已保存和还没保存的手动值都默认不勾。追加查询 OpenRouter 保留已有选择；它只作目录参考，不越过本地权威来源。
- 原三个入口收成一个复核流程，与现有设置弹窗、字号和窄屏样式对齐。

## 验证

原生浏览器拖拽、正文位置、草稿恢复与取消引用、实际 Pi 路径提交、项目名称搜索及键盘操作均已验证。测试使用隔离项目和 localhost MiniMax fixture，无外部付费模型调用。定点回归与最终发布状态见对应 PR。
