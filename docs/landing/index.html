三大核心能力

🎯

统一 TUI 启动

一个命令 mms 进入交互界面，方向键选模型，回车直接启动。告别繁琐的环境变量配置。

$ mms --preset coding
⚡

快速切换 Provider

临时切换模型源或账号，一行命令搞定。不污染 shell 配置，用完即走。

$ mms claude --provider foo
🔧

环境导出 & 诊断

一键导出环境变量供脚本使用，内置 doctor 命令快速诊断 provider 健康度。

$ mms env my-preset --apply
