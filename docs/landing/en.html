What MMS gives you

One TUI

Browse model families, compare compatible channels, and launch sessions from a single interface instead of memorizing provider-specific commands.

$ mms

Provider + account routing

Mix gateway providers and official OAuth accounts in one config surface. MMS keeps priority, role, and bridge compatibility consistent.

$ mms claude --provider openrouter

Diagnostics and exports

Use route export, doctor, warm, and trace tooling when you need to debug a provider or let external tools consume the resolved routing contract.

$ mms routes export
