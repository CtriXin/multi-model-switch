通道配置

先建通道：基础信息、连接凭据和策略项在通道配置；模型能力、使用次数、隐藏/补充模型在模型配置。Key 只会通过 POST 发送，不会回显。

这里直接改 MMS 启动会读取的模型能力。`文本显示` 决定普通模型列表，`1M` 会写入 `context_window_tokens=1000000`；使用次数用于判断默认模型、priority 和能力参数。

模型拉取会先进入页面草稿；使用次数刷新只更新本页统计，不写配置。

已知能力快照

本地快照不联网；OpenRouter catalog 会联网读取结构化字段，但它是 provider catalog 参考，不是厂商官方真值。结果都只进草稿，保存预览后才生效。

模型配置动作结果会显示在这里。

模型测试

支持模型列表 smoke、指定模型 ping/pong 和简单 chat。结果会显示脱敏 request_url/request_path evidence。

执行 /models、Ping 或简单对话后，这里显示可读摘要；原始响应在高级模式展开。
