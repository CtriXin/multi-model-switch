通道配置

先建通道：基础信息、连接凭据、策略高级项和报告确认分在编辑器 Tab 中；Key 只会通过 POST 发送，不会回显。

这里配置当前通道会给 MMS 看到哪些模型，以及这些模型能不能做文本、看图、工具调用、思考、长上下文和缓存敏感路由。取消「显示」会写入 hidden_models；取消「文本」会同步隐藏，避免普通启动页继续展示。

能力开关怎么影响启动

「显示/文本」决定普通模型选择是否出现；「看图」决定 vision sidecar 候选；「缓存敏感」会让双协议模型优先走更安全的 messages 路径。长上下文是能力标记，Claude 1M 还要看通道里的 Claude 1M / [1m] selector。

模型配置动作结果会显示在这里。

运行默认值

首选 CLI 会写入 presets.coding.cli；OpenCode profile 和 agent roster 会写入 [opencode]，launcher 会生成 session-local opencode.json；不会写全局 OpenCode 配置。

OpenCode Agent 名单

Lean 默认只开关键链路；Balanced 适合日常；Deep 再启用第二意见。国产模型适合 explore / bughunt / vision，不默认做最终裁决。
