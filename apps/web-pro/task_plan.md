# 角色委员会功能任务计划

## 目标

将现有 `Discuss` 升级为“AI 角色委员会”体验，提供 12 个预设角色、3 种运行模式，并确保不同角色输出具有清晰张力与稳定立场。

## 阶段

| 阶段 | 状态 | 说明 |
|------|------|------|
| 1 | complete | 读取现有 `Discuss` 页面、store、mock 数据与共享 contracts |
| 2 | complete | 已落地角色委员会数据结构、模拟运行逻辑与模式编排 |
| 3 | complete | 已改造 `Discuss` 页面与相关组件，加入角色、模式与结果展示 |
| 4 | complete | 已更新入口文案、记录文件并完成 `npm run build` 验证 |

## 关键决策

- 直接扩展现有 `Discuss`，不新增独立路由，减少切换成本。
- Phase 1 先用 mock 数据完整跑通“12 角色 + 广播/辩论/委员会”交互。
- “综合与决策”不建成角色，而作为 `委员会模式` 的系统级汇总输出。

## 验证计划

- `npm run build`
- 检查页面是否能在桌面与移动布局下展示角色矩阵和模式切换

## 错误记录

| 错误 | 次数 | 处理 |
|------|------|------|
| `DiscussPane.vue` 中 `RoleCategoryId` 被推断成 `string` | 1 | 为角色分组种子补显式类型，重新构建通过 |
| `DiscussPane.vue` 模板新增结构化委员会区块时缺少闭合标签 | 1 | 补齐 `section` 结束标签后重新构建通过 |
