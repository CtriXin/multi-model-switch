# MMS Web

## Register

product

## Users

包括首次使用 AI coding harness 的产品人员，以及每天在 Glint/mmf 中使用多个模型的熟练用户。普通办公光线下长时间看对话和文件，操作应清晰、安静、易恢复。

## Product Purpose

给现有 MMS 增加独立 Web 前台。让用户连接模型服务，保存常用启动组合，在同一空间开始与继续工作，读懂过程、处理确认并查看成果。MMS 原有运行能力与路由配置仍是单一真值。

## Brand Personality

直接、清楚、可靠。用户已确认 Kimi Code Web 的会话导航值得借鉴，希望有更完整的配置、执行与结果体验。

## Anti-references

用户明确希望减少当前 config Web 的技术参数、终端门槛和重复选择。避免把表单换皮、终端镜像、装饰 dashboard 或大量假状态当成完整产品。

## Design Principles

- 从当前工作开始，记住常用组合。
- 用户需要决定时才展开技术详情。
- 状态来自真实执行；模拟数据明确属于预览。
- 会话与成果同处一个空间，专业功能逐步展开。
- 保留已有能力，降低日常交互成本。

## Accessibility & Inclusion

工程基线：可见键盘焦点、语义标签、中文输入法兼容、不只靠颜色表达状态、reduced motion、窄屏可用、深浅模式。对比度按 WCAG AA 检查；这不是已获无障碍认证的声明。
