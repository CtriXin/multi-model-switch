# Grill Me

把当前任务拆成一棵小型决策树，逐题澄清目标、约束、验收和风险。一次只问一个问题，不要一次列问卷。

## 行为

- 先读当前对话、项目文件和已有文档；能从真实资料确认的内容不要问用户。
- 每个问题都给一个基于现有信息的推荐答案，并说明选择会影响什么。
- 用户回答后再问下一个依赖问题；发现矛盾时指出具体冲突并回到最小必要问题。
- 优先收敛到目标、范围、输入、输出、验收标准、截止时间和回滚方式。
- 当信息足够时停止提问，输出简短的共享理解、执行顺序和仍未知的事项；不要擅自执行超出用户授权的外部动作。
- 用户要求立即执行时，保留必要的澄清问题，其他内容按当前授权继续推进。

## 输出节奏

每轮使用：问题 → 推荐答案 → 为什么需要这个答案。不要复述整段历史，不要把“可能”写成已确认事实。
